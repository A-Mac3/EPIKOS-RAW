# Lensfun lens database

These XML files are the lens and camera database of the Lensfun project
(https://github.com/lensfun/lensfun, `data/db`, commit bbd4332a9ec5, 2026-09-24),
included unmodified.

Lensfun contributors. EPIKOS RAW reads the distortion, lateral chromatic aberration and
vignetting calibrations from these files; any changes made to them must be shared under
the same license.
